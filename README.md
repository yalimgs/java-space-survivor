# Space Survivor

A 2D top-down space arcade survival game built in Java using the `StdDraw` library. Control a spaceship, blast through meteors and alien waves, collect power-ups, and defeat challenging bosses.

## 🚀 Features

* **Combat:** Smooth movement, meteor destruction, and hostile alien fights.
* **Power-Ups:** Multi-shot upgrades, energy shields, and score bonuses.
* **Boss Fights:** Challenging boss encounters with high health and unique attacks.
* **Progression:** Dynamic difficulty scaling as you survive longer.

## 🛠 Tech Stack

* **Language:** Java
* **Library:** Princeton `StdDraw`
